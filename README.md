# pb-inpx-dl

Каталог книг для PocketBook Verse Pro (PB634). Без адреса INPX приложение открывает Флибусту через OPDS, а кнопка INPX видна в шапке и неактивна. Если указан адрес сервера INPX Web, приложение открывает его каталог при запуске, а в шапке можно переключаться между источниками. Книги сохраняются в штатную папку Downloads.

## Установка

1. Подключи Verse Pro по USB в режиме связи с компьютером.
2. Распакуй `pb-inpx-dl-pb634.zip`. Скопируй `pb-inpx-dl.app` в папку `applications/` ридера, а BMP-файлы из `applications/icons/` — в одноимённую папку ридера. При новой установке конфиг нужен только для своих адресов каталогов. При обновлении переименуй прежний конфиг в `pb-inpx-dl.toml`, чтобы сохранить логин и пароль. Если уже выбирал языки, переименуй прежний файл настроек в `pb-inpx-dl-preferences.toml`.
3. Если в `system/config/desktop/view.json` есть пользовательская запись «Каталог книг», укажи в ней новый путь `/mnt/ext1/applications/pb-inpx-dl.app` и пути `applications/icons/pb-inpx-dl.bmp` и `applications/icons/pb-inpx-dl_f.bmp` для обычного и выделенного значков.
4. Безопасно извлеки ридер, отключи кабель и открой приложение в меню PocketBook.

Чтобы подключить INPX Web, скопируй пример `pb-inpx-dl.toml` в `system/config/`, раскомментируй `inpx_ws_url` и подставь адрес своего сервера. Можно указать только HTTPS-адрес сервера в `inpx_http_url`: приложение добавит к нему путь `/ws` для WebSocket. Если сервер отдаёт HTTP-файлы по отдельному адресу, задай оба поля. В существующих конфигах также поддерживается `catalog_url`.

Языки книг для обоих источников выбираются через шестерёнку в шапке приложения → «Языки книг». По умолчанию выбраны русский и английский. Можно выбрать «Все языки» или добавить язык по коду. Кнопка «Применить» сохраняет выбор в `system/config/pb-inpx-dl-preferences.toml`. Пока этого файла нет, приложение учитывает языки из основного конфига.

Чтобы задать логин и пароль, открой шестерёнку → «Аккаунт Флибусты» и нажми «Применить». Данные сохраняются в том же файле настроек на ридере и действуют сразу. Кнопка «Удалить данные входа» переключает каталог на доступ без аккаунта. До первого изменения аккаунта приложение использует `username` и `password` из раздела `[flibusta]` основного конфига. Если эти поля были заполнены вручную, удалить их из основного конфига тоже можно вручную. Там же задаётся HTTPS-адрес каталога `opds_url`.

Обложки кэшируются в `system/cache/pb-inpx-dl/` (до 24 МиБ).

Для проверки настроенного каталога INPX на ридере выбери INPX в шапке, введи `паланик колыбельная`, открой карточку Чака Паланика и скачай исходный FB2. Файл должен появиться в штатной библиотеке в разделе Downloads без перезагрузки. Если приложение закрылось с ошибкой, ищи диагностический файл `system/pb-inpx-dl.log`.

## Сборка

На компьютере нужны Rust 1.99.1, Zig 0.15.2, cargo-zigbuild 0.24.1 и `zip`.

```sh
rustup target add armv7-unknown-linux-gnueabi
cargo install --locked cargo-zigbuild --version 0.24.1
cargo test --locked --lib
./scripts/package.sh
```

Пакет появится в `dist/pb-inpx-dl-pb634.zip`. Сборка ориентирована на ARMv7 с soft-float ABI и InkView 6.10. Интерфейс использует системный шрифт ридера.
